# Christopher Holt Portfolio

## Introduction

Welcome to my portfolio. I am interested in programming in Javascript and C++. I wanted to showcase a fun project for my portfolio so I created this Windows 10 inspired project. It has a Start Menu, My Computer, Browser and even a Command Prompt that you can view the projects that I have created in multiple different ways. You can navigate the website just like you would a normal desktop.

### How to Use
[Portfolio Link](https://christopher-holt-portfolio.web.app/)

As I said before you can navigate the website using multiple different ways. I would recommend if you know lots about programming going through the command prompt, you just need to type commands into the input field to view the different parts, when you first start the website it will show the command prompt and the help command that will help you understand what prompts to use.
Alternatively you can double click on the My Computer to see the projects that I have created or you can double click on the Browser to see everything that the Command Prompt has, just in a different way.
Lastly you can use the start menu to just see an overview of what the other options have.

### Technologies used

This project has been created in React using Javscript and vanilla CSS.

### Motivation

I had an old portfolio which looked dated and didnt really feel like me, so I wanted to create something that was fun, a bit more challenging and I could continue to iterate over it continously so here we are, a fun Windows 10 portfolio, with a very small version of an operating system inside of the web browser, I hope you enjoy it!
